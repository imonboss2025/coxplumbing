### Option B — Google Places API (New) — Live fetch with your own key

Use this to fetch and render reviews yourself, with full control over styling.

**Requires:** Google Cloud account + Places API (New) enabled + billing linked (has a free monthly credit).

#### API Endpoint

```
GET https://places.googleapis.com/v1/places/ChIJz9wjoZ2oBYgRmR2icADrY_Q
```

#### Required headers

```
X-Goog-Api-Key: YOUR_GOOGLE_MAPS_API_KEY
X-Goog-FieldMask: displayName,rating,userRatingCount,reviews
```

#### Full curl example (for testing)

```bash
curl -X GET \
  "https://places.googleapis.com/v1/places/ChIJz9wjoZ2oBYgRmR2icADrY_Q" \
  -H "X-Goog-Api-Key: YOUR_GOOGLE_MAPS_API_KEY" \
  -H "X-Goog-FieldMask: displayName,rating,userRatingCount,reviews"
```

#### Example JSON response shape

```json
{
  "displayName": { "text": "Cox Plumbing Co. Inc." },
  "rating": 4.2,
  "userRatingCount": 74,
  "reviews": [
    {
      "name": "places/ChIJz9wjoZ2oBYgRmR2icADrY_Q/reviews/...",
      "relativePublishTimeDescription": "2 months ago",
      "rating": 5,
      "text": { "text": "Jeff is Wonderful!...", "languageCode": "en" },
      "authorAttribution": {
        "displayName": "Jane D.",
        "photoUri": "https://..."
      }
    }
    // up to 5 reviews returned (Google's limit)
  ]
}
```

> ⚠️ **Google only returns the 5 most recent reviews** via the API — there is no way to retrieve all 74 reviews programmatically through the Places API.

#### JavaScript fetch snippet (drop into any webpage)

```html
<div id="google-reviews"></div>

<script>
const PLACE_ID = "ChIJz9wjoZ2oBYgRmR2icADrY_Q";
const API_KEY  = "YOUR_GOOGLE_MAPS_API_KEY"; // ⚠️ use a restricted key

async function loadReviews() {
  const res = await fetch(
    `https://places.googleapis.com/v1/places/${PLACE_ID}`,
    {
      headers: {
        "X-Goog-Api-Key": API_KEY,
        "X-Goog-FieldMask": "displayName,rating,userRatingCount,reviews"
      }
    }
  );
  const data = await res.json();
  const container = document.getElementById("google-reviews");

  container.innerHTML = `
    <h3>${data.displayName.text}</h3>
    <p>⭐ ${data.rating} / 5 — ${data.userRatingCount} reviews</p>
    ${data.reviews.map(r => `
      <div class="review">
        <strong>${r.authorAttribution.displayName}</strong>
        <span>${"⭐".repeat(r.rating)}</span>
        <p>${r.text.text}</p>
        <small>${r.relativePublishTimeDescription}</small>
      </div>
    `).join("")}
  `;
}

loadReviews();
</script>
```

> 🔒 **Security note:** Never expose your raw API key in frontend code. Either restrict the key to your domain in Google Cloud Console, or proxy the request through a backend/serverless function.

### To customise

| What to change | Where in the code |
|---|---|
| Add / remove review cards | Duplicate or delete any `<div class="card">` block |
| Change scroll speed | `.row-1` animation duration (`38s`) and `.row-2` (`44s`) |
| Change card width | `.card { width: 360px }` |
| Adjust text clamp | `.review-text { -webkit-line-clamp: 4 }` |
| Update rating number | `.rating-number` text and star `filled`/`partial` classes |
| Change CTA link | `href` on `.cta-link` anchor |
| Reviewer avatar color | `.av-blue`, `.av-copper`, `.av-teal`, `.av-purple`, `.av-slate`, `.av-rose` classes |
| Pause on mobile | Remove `:hover` animation-play-state rule or set to always paused |
